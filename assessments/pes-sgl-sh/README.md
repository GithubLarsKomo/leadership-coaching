# PES / SGL Schleswig-Holstein

First domain pack for Leadership Assessment Coaching.

The included scorecard is a **coaching model**, not a claim to reproduce a confidential or official internal observer matrix. Publicly documented role expectations and later verified primary sources can be incorporated through explicit new versions.

Baseline round 1 is deliberately locked and timed. Its hidden competency mapping is coach-side metadata and must not be exposed to the candidate during the active assessment block.
